You will receive a table, and a list of (question, explanation, answer) triples.
Perform three tasks **in order** and output the results in the exact format shown.

--------------------------------------------------------------------
## Task 1 — Question Relevancy  (rel)
- **relevant**   : The question can be answered with the given table.
- **irrelevant** : The table does not contain the information to answer.
- **unsure**     : Ambiguous; cannot decide from the table.

### Output →  
rel: relevant / irrelevant / unsure

--------------------------------------------------------------------
## Task 2 — Question Type Classification  (Type)  
*Only perform Task 2 if `rel = relevant`; otherwise set `Type: N/A`.*

Choose one subtype below.  Follow the **boundary rules**:

| Type | Core Idea | Boundary Rules (clarified) |
|----------|-----------|----------------------------|
| Specific Cell Comparison | Compare explicit cells | e.g. “Row 1 Col A vs Row 3 Col A” |
| Specific Condition Comparison | Compare rows/cols filtered by a condition | e.g. “values > 0.5” |
| Difference Calculation | **Exactly two** values → absolute gap | If > 2 values → **not** this type |
| Ratio Calculation | **Exactly two** values → percent/ratio | More than two values → Change/Trend |
| Change Analysis | 3 + values **within the same row _or_ same column** | Cross‑row+col → Trend |
| Trend Comparison | 4 + values spanning **≥ 2 rows & ≥ 2 columns**, or comparing multiple computed gaps | |
| Average/Sum Calculation | Compute mean or sum of 3 + values | |
| Maximum/Minimum Identification | Identify highest/lowest among 3 + values | If only 2 values, use Specific Cell Comparison |

**Decision Criterion:**  
Base your sub-type classification **on the Explanation**, not just the Question.  
Specifically, analyze:
- The **number of raw data points** explicitly compared or aggregated (e.g., 2 vs 3+ vs 4+),
- The **structure of the reasoning** (e.g., single row/column vs multiple rows and columns),
- Whether the reasoning involves **filtering**, **trend comparison**, **aggregation**, etc.

**If none of the above sub-types clearly apply, set `Type: N/A`.**

### Output →  
Type: {one of the eight sub‑types above | N/A}

--------------------------------------------------------------------
## Task 3 — Answer Correctness  (cor)  
*Skip if `rel = irrelevant`; use `cor: N/A`.*

- **correct**   : Answer matches the table regardless of explanation quality.  
- **incorrect** : Mismatch with the table **or** there are multiple correct answers but only one is given.  
- **unsure**    : Data missing/ambiguous.

### Output →  
cor: correct / incorrect / unsure / N/A

--------------------------------------------------------------------
