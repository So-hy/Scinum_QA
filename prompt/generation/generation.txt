##  Task Guidelines for Objective and Concise Table-based Q&A Generation

### 1. Types of Questions

Create exactly **one question per Type**, ensuring objectivity, clarity, and brevity. Each question must have only one correct answer, expressed concisely.

- **Type 1. Specific Cell Comparison**  
  - Directly compare exactly two specific cells.  

- **Type 2. Specific Condition Comparison**  
  - Compare values that satisfy a clearly stated condition.  

- **Type 3. Difference Calculation**  
  - Calculate the absolute difference between exactly two cells.  

- **Type 4. Ratio Calculation**  
  - Calculate the relative change (%) from one specific cell to another.  

- **Type 5. Change Analysis**  
  - Analyze changes within exactly one row or one column using at least 3 data points.  
  - *If the table has more than 3 points in that row/column, feel free to include them to increase depth.*  
  - The **answer must be purely numeric** (e.g., the largest absolute change) — do **not** output words such as “Increase”, “Decrease”, “No Change”, “Mixed”, nor variants like “increasing” or “decreasing”.
  - Example: "Comparison of values in columns A, B, and C of row 1"

- **Type 6. Trend Comparison** 
  - Must compare values from **at least two rows across at least two columns** (≥ 4 cells).  
  - Step 2 of the Explanation must explicitly list every row and column referenced.  
  - If only one row or one column is used, the question is invalid (that would be Type 5).
  - Example: "Comparing Rows 1–3 across Columns A–C"

- **Type 7. Average/Sum Calculation**  
  - Compute the sum or average of exactly specified cells.  
  - *If the selection includes more than the minimum, you may include them.*  

- **Type 8. Maximum/Minimum Identification**  
  - Identify the single highest or lowest value among at least 3 specified cells.  
  - *When the table permits, consider more cells to make it more challenging.*  

---

### 2. Steps to Generate Questions

Follow these steps carefully:

- **Step 1: Table and Caption Analysis**  
  Understand the primary purpose and main content of the provided table.

- **Step 2: Check Type Requirements**  
  Review carefully the conditions required for each Type as specified above.

- **Step 3: Table Structure Examination**  
  Identify clearly which cells or ranges are suitable. Pay special attention to merged cells. Pay extra attention to merged rows or columns—ensure you interpret spanning cells correctly before selecting.

- **Step 4: Precise Cell Selection**  
  Clearly specify exact cell positions needed to answer the question.

- **Step 5: Generate One Objective Question per Type**  
  Ensure each question leads to a single, objectively correct answer.
  **When crafting the question and answer, strictly follow the phrasing and style of the few‑shot examples.**

- **Step 6: Reasoning and Answer Generation**  
  Clearly document the reasoning steps needed to solve the question, and concisely state the final answer resulting from this reasoning.

---

### 3. Output Format

Strictly follow this format, using '|||' as delimiter, and output exactly eight lines. Do not include any text outside of these lines.
Type|||<Type Name>|||Question|||<Your generated question>|||Explanation|||Step 1=<Brief reason for choosing this Type>|||Step 2=<Exact cell specification and concise calculation or reasoning>|||Answer|||<Final concise answer>

**Example:**
Type|||Ratio Calculation|||Question|||By what % did Row 2 Column B increase compared to Row 1 Column B?|||Explanation|||Step 1=Calculate relative % difference between two clearly specified cells|||Step 2=(Row2B - Row1B) / Row1B × 100%|||Answer|||20%

---

### 4. Important Notes
- All explanations and answers must be concise and numeric (or clearly defined short text if numeric not applicable).
- Avoid any subjective terms (e.g., "significantly", "slightly", "substantially") or ambiguous descriptions.
- Do **not** use qualifiers like “Approximately” or “About”; if you need to indicate an approximation, use the “~” symbol (e.g., '~0.12').
- Each generated question must have exactly one correct answer, phrased so any model or person would answer identically.
- Do **not** include any additional text outside of the provided format.
- Do **not** use qualitative descriptors (e.g., “slight increase”); answers must be one of:
  1. A numeric value or calculation (e.g., '0.12', '5.3%'),  
  2. A predefined label ('Yes'/'No'), or  
  3. Exact text from the table (e.g., model names, specific cell entries).
